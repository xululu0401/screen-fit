# 幕布别买大了（screen-fit）

把能买到的几个投影幕布尺寸并排过四道关：墙放得下吗、坐着看视角在不在区间、投影机按投射比要放的位置能不能装、幕面亮度够不够。挑出四关都过的最大号；想买的那个没过，给出只改一项就能过的改法，每条回填重算。

- 单文件页面：`index.html`（由 `template.html` 经 `build.cjs` 产出）+ `core.js`（纯计算）+ `ui.js`（界面）
- 测试：`node --test tests/core.test.cjs`
- 公式：画面宽 = 对角线 × r ÷ √(r² + 1)；水平视角 = 2·atan(半宽 ÷ 座位距离)；投影距离 = 投射比 × 画面宽；nit = 流明 × 打折 × 增益 ÷ (π × 面积 m²)（朗伯面近似）
- 默认场景为虚构示例；视角 30°–40°、亮度目标 80 nit、流明打七五折都是可改的设计值，不是标准或实测。
